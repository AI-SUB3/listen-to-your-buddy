## 這是什麼

104 個依 [UBERON](https://obophenotype.github.io/uberon/) 本體論標註的解剖結構，分屬全身（男性／女性）與腦部三份圖版。每個結構附概述、構造、功能、量化數據與臨床要點五個分頁。

除了當參考書讀，它還有第二個用途：在圖版上落針，把自己從小到大受過的傷一筆一筆記下來。

整個網站是**單一個 HTML 檔案**，沒有後端、沒有資料庫、沒有帳號系統，也沒有任何追蹤。

## 兩個模式

### 圖譜

右上角可切換男性與女性圖版；兩張圖對位在 3% 以內，共通 68 個結構，各自另有獨有的部分。點圖上的結構，或用左欄索引搜尋中文、英文、拉丁名與 UBERON 編號。選取後會從結構重心拉出一條引線到圖版邊緣，附上拉丁學名與本體論編號——銅版解剖圖的標號慣例。

內臟本來就層層相疊，所以在同一點連續點擊會往下一層走，滑鼠提示會顯示目前在第幾層。

### 傷害誌

在圖版上點一下就標出一個部位。座標存的是圖版自身的 SVG 座標，不受本體論覆蓋範圍限制——踝、膝、肩這些圖上沒有標註的地方一樣標得了。若落點剛好在已標註的結構上，會自動帶入名稱與 UBERON 編號。

資料分兩層：**部位 → 傷害紀錄[]**。同一個右外踝扭三次是一個部位掛三筆紀錄，復發次數會自己浮出來。每筆記錄受傷日期、痊癒日期、類型、程度、成因、當時活動、休養天數、診斷與影像、治療與復健、備註與目前狀態。

日期接受 `2015`、`2015-08`、`2015-08-14` 三種精度——童年的事情很多只記得年份，逼人填完整日期只會讓人亂填。

刪除不會跳確認視窗，而是可以在十四秒內按「復原」救回來，連同該部位底下的所有紀錄。

圖版下方是一條生命時間軸，年份在下、年齡在上（設定出生年後出現）。填了痊癒日期的紀錄會畫成長條而不是圓點，一眼看出哪段時間是帶傷的；狀態為「慢性未癒」的則畫到今天為止。

左下角的「列印摘要」會產生一張適合帶進診間的表：統計、時間軸、依部位分組的完整紀錄，黑字白底可直接列印或存成 PDF。

## 你的紀錄存在哪

> [!IMPORTANT]
> **紀錄只存在你打開網站的那台裝置上。** 資料寫進瀏覽器的 localStorage，從來沒有離開過你的電腦或手機——沒有伺服器在收，也沒有地方可以收。
>
> 也正因為如此，**換一台裝置、或清除瀏覽資料，紀錄就會永久消失，沒有任何地方可以救回來**。請用左下角的「匯出 JSON」定期備份。

> [!CAUTION]
> **iPhone、iPad 使用者請務必把這個頁面加到主畫面。** Safari 會在七天沒有開啟該網站之後，自動清除它儲存的所有資料。iOS 上的 Chrome 與 Firefox 也一樣，因為它們底層都是 Safari。
>
> 按分享鍵 →「加入主畫面」，從主畫面開啟的版本不受這條規則限制。網站偵測到 iOS 時也會顯示這則提醒。

這代表：

- 每個打開這個連結的人，看到的都是自己的紀錄。彼此看不到，連分享連結的人也看不到。
- 換一台裝置就是另一份空白的紀錄，不會同步。
- 清除瀏覽器資料會一併清掉它。

所以請**定期匯出備份**。左下角的「匯出 JSON」按鈕會直接顯示還沒備份的筆數，旁邊的燈號會隨著累積量從灰轉黃再轉紅。存下第一筆紀錄時、累積五筆未備份時、或上次備份超過九十天時，會跳出一次提醒並附上直接匯出的按鈕——其餘時候不打擾。匯入時可以選擇合併或取代。

匯出的格式是可讀的 JSON，帶有結構版本號，舊檔匯入時會自動升級：

```json
{
  "version": 2,
  "birthYear": 1990,
  "sites": [
    { "id": "a1b2c3", "view": "body", "x": 52.0, "y": 178.4,
      "label": "外踝", "side": "右", "uberon": null }
  ],
  "injuries": [
    { "id": "d4e5f6", "siteId": "a1b2c3", "date": "2026-08-09",
      "until": "2026-08-30",
      "type": "韌帶扭傷", "severity": 2, "cause": "訓練",
      "status": "反覆發作", "activity": "越野跑下坡", "downtime": "21",
      "dx": "超音波：前距腓韌帶第一度撕裂", "tx": "冰敷加壓、腓骨肌與平衡訓練",
      "notes": "" }
  ]
}
```

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個網站，單一檔案自足 |
| `guide.html` | 給一般使用者的說明書、Q&A 與更新紀錄 |
| `manifest.json` | 讓它可以安裝到主畫面 |
| `sw.js` | Service worker，離線也能開啟 |
| `icon-192.png` · `icon-512.png` | 應用程式圖示 |
| `apple-touch-icon.png` | iOS 主畫面圖示（180×180） |
| `og-cover.png` | 分享到社群時的預覽圖（1200×630） |

安裝到主畫面後，整個網站會離線可用——它本來就沒有後端，快取住那一個 HTML 檔就等於快取住全部功能。

要自己架一份的話，把這些檔案放進任何靜態空間即可（需要 HTTPS，service worker 才會啟用）。如果換了網址，記得改 `index.html` 開頭的 `og:url`、`og:image`、`twitter:image` 與 `canonical` 四個絕對網址，以及 `manifest.json` 裡的 `id`。

## 免責聲明

此頁供學習與個人紀錄使用，**不構成醫療建議，也不能取代專業診斷**。

「診斷與影像」欄位是用來抄寫你已經從醫療人員那裡取得的診斷，不是用來自我判斷的。文中的數值都是健康成人的典型範圍，個體差異很大，只能給個比例感。身體有狀況請找醫師。
